# 60 세공 도우미 (마인크래프트 모드) — rev31 (v0.14.0)

띵타이쿤(Fabric 1.21.4)용 **클라이언트 전용** 모드입니다.
세공 창의 모듈 칸에 보석을 넣으면 "광채를 몇 개 쓰면 되는지" 추천 카드를 보여줍니다.

## 하는 일
1. 보석 툴팁의 **순도 / 광도 / 강도** 와 등급(COMMON/NORMAL/RARE)을 읽습니다.
2. 광채(바이올렛 / 오팔 / 아다만티움) 개수는 오른쪽 패널이 아니라 **내 인벤토리를 직접 세서** 알아냅니다.
3. 합이 한도(200 / 212 / 236) 이하가 되는 가장 좋은 사용 개수를 계산해 보여줍니다.

세공 화면이 열려 있는 동안은 마우스를 올리지 않아도 모듈 칸의 보석을 읽어 계속 표시합니다 (rev2). **v0.13.1부터는 기본으로 이 경우에만** 카드가 나옵니다. v0.14.0부터는 설정의 **미리보기**를 켜면 인벤토리 등에서 보석에 마우스만 올려도 카드가 나옵니다 (아래 v0.14.0 설명).

서버에 패킷을 보내거나 아이템을 대신 클릭하지 않습니다. **보기만 하는 모드**입니다.

## 카드 위치 옮기기
세공 화면(또는 다른 화면)이 열려 있고 추천 카드가 떠 있을 때, 카드 위에서 **마우스 왼쪽 버튼을 누른 채 끌면** 원하는 곳으로 옮길 수 있습니다. 놓으면 그 위치가 저장됩니다. 설정 화면의 "위치 초기화"로 자동 위치로 되돌립니다.

## 설정 화면
게임 중(화면이 없을 때) `K` 키 또는 `/세공 설정` 으로 엽니다.
- 동작: 켜짐/꺼짐
- 표시 방식: 타일형(기본) / 카드형 / 한 줄형 / 슬롯 배지형
- 디자인: **다크 약방**(기본, 어두운 갈색 판 + 주황 조각 액자 + 금 못 + 리본 제목 + 둥근 메달) / 우드카드(나무판 + 못) / 크림(이전 디자인). 타일형·카드형·한 줄형·슬롯 배지형 카드와 이 설정창 모두에 적용됩니다. (v0.4.0에서 추가. 디자인 저장 값이 새로 바뀌어서, 업데이트 직후에는 다크 약방으로 시작합니다.)
- 아이콘: 켜짐/꺼짐 (v0.5.0에서 추가). 켜면 다크 약방 디자인의 타일형·카드형(이름 앞, 통계 줄 앞)과 한 줄형·슬롯 배지형에서 바이올렛/오팔/아다만티움 이름 앞(타일형은 이름 위, 통계 줄 앞도)에 **내 인벤토리에 있는 그 광채 아이템 그림**을 그립니다. 그 광채를 인벤토리(또는 열린 창고/세공 칸)에서 **한 번 본 뒤부터** 보이고, v0.8.1부터는 그 그림을 설정 파일에 저장해 두어서 **인벤토리에 광채가 없을 때나 게임을 껐다 켠 뒤에도** 계속 보입니다. 아직 한 번도 못 봤으면 색깔 동그라미로 대신합니다. 한 줄형은 이름 대신 아이콘 + 개수로, 슬롯 배지형은 둘째 줄(순도·광도·강도) 항목 앞에 아이콘이 나옵니다. 우드카드·크림 디자인의 타일형·카드형에는 아이콘이 없습니다.
- 추천 고정: 켜짐(기본)/꺼짐 (v0.5.1에서 추가). 켜면 보석을 처음 본 순간 정한 목표(최종 순도/광도/강도)를 광채를 넣는 동안 그대로 유지하고, 숫자는 "남은 개수"만 줄어듭니다. 아래 "추천 고정" 설명 참고.
- 미리보기: 꺼짐(기본)/켜짐 (v0.14.0에서 추가). **꺼짐**이면 세공 창 모듈 칸에 보석이 있을 때만 카드가 나오고, **켜짐**이면 인벤토리·창고 등 어디서든 보석에 마우스만 올려도 카드가 나옵니다 (보석을 모듈 칸에 넣기 전에 미리 보고 싶을 때).
- 오늘한 세공: 켜짐/꺼짐 + **통계 보기** 버튼 (v0.13.0). 켜면 카드 아래에 오늘 한 세공 작은 표가 나옵니다. "통계 보기"는 통계 창을 엽니다. 아래 "오늘한 세공 · 통계 창" 설명 참고.
- 글자 크기: 슬라이더 (0.7 ~ 1.5배)
- 위치 초기화
- 등급: 자동이 안 될 때만 쓰는 수동 한도
- 학습한 등급 표시 지우기 (기본값으로)
- 설정 기본값으로 (v0.6.0): 위 설정을 전부 처음 상태로 되돌립니다. 실수로 누르지 않게 **두 번 눌러야** 합니다 (처음엔 "한 번 더 누르면 초기화"로 바뀜, 다른 버튼을 누르면 취소). 학습한 등급 표시는 그대로 둡니다.
설정은 게임을 껐다 켜도 유지됩니다. (설정 파일 `config/segong.properties` 의 `design`, `icons` 등)

### 오늘한 세공 · 통계 창 (v0.13.0)
**어떤 보석을 몇 번 세공했는지**를 날짜별·보석별·등급별로 모아 둡니다. (v0.13.0에서 "오늘 세공 N회" 횟수 표시는 없어지고, 이 기록과 통계 창으로 합쳐졌습니다.)
- **세는 때**: 보석 하나에 **추천한 개수를 다 넣어서 순도·광도·강도가 추천 수에 도달했을 때** 1번으로 셉니다. 광채를 하나 넣을 때마다 세지 않습니다. 처음부터 넣을 광채가 없던 보석(이미 끝난 보석, "추가 필요 없음")이나, 끝내지 않고 치운 보석은 세지 않습니다. 그때 그 보석의 **이름**(예: 키론)과 **등급**(Common/Normal/Rare 등)을 같이 적습니다.
- **카드 아래 작은 표 "오늘한 세공"**: 오늘 많이 한 순서로 최대 4줄 (예: `테라온 Rare 3회`). 5종 이상이면 "외 N종". 카드를 옮기면 같이 따라가고, 아래에 자리가 없으면 카드 위로 붙습니다. 설정의 "오늘한 세공"에서 끌 수 있습니다.
- **통계 창**: 채팅창에 `/세공 통계` 를 입력하거나, 설정 창의 **통계 보기** 버튼을 누르면 열립니다. (닫기 버튼 또는 Esc 로 닫습니다. 설정 창에서 열었으면 닫을 때 설정 창으로 돌아옵니다.)
  - 위쪽 탭: **오늘 · 7일 · 30일 · 전체**. 오른쪽에 그 기간의 "합계 N회 · 하루 평균 X회". 하루 평균은 합계를 (기록을 처음 시작한 날 또는 기간의 첫날부터 오늘까지의 날 수)로 나눈 값입니다.
  - 날짜별 **막대 그래프**: 오늘·7일 탭은 최근 7일, 30일·전체 탭은 최근 30일을 보여줍니다. 오늘 막대는 금색. 막대를 누르면 **그 날만 자세히** 보고, 같은 막대를 다시 누르면 기간 전체로 돌아갑니다 ("기간 전체 보기" / "오늘로" 버튼으로도 돌아갑니다).
  - 아래 표: 기간 전체를 볼 때는 **보석 × 등급**(Common · Normal · Rare · Epic↑) 표와 맨 아래 합계. `Epic↑` 칸에는 Epic·Legendary·Mythic 과 등급을 못 읽은 것("등급?")이 같이 들어갑니다. 한 날을 볼 때는 줄마다 보석 이름 · 등급 · 막대 · 횟수.
  - **고치기**: 한 날을 볼 때 줄 오른쪽의 `-` `+` 버튼으로 횟수를 1씩 고칩니다 (0이 되면 그 줄이 없어집니다). 잘못 센 기록을 고치거나, 빠진 기록을 더할 때 쓰세요.
  - **방금 기록 취소**: 방금 쌓인 기록 하나를 되돌립니다. 게임을 껐다 켜면 "방금" 기록은 잊어서 흐리게 나옵니다 (그땐 `-` 로 고치세요).
  - **전체 기록 지우기**: 실수로 누르지 않게 **두 번 눌러야** 합니다 (처음엔 "한 번 더 누르면 모두 지워요"로 바뀜, 다른 걸 누르면 취소). 되돌릴 수 없습니다.
  - 줄이 많으면 표 오른쪽 `▲` `▼` 버튼이나 마우스 휠로 넘깁니다.
- **파일**: `config/segong-journal.tsv` (날짜, 등급, 이름, 횟수 — 탭으로 구분한 글자 파일). 400일이 지난 기록은 지웁니다. 날짜는 하루가 바뀌는 시각 기준(기본 0시, 설정 파일 `config/segong.properties` 의 `tally.reset`)입니다.
- 보석 이름은 아이템 설명 맨 윗줄에서 등급 글자·특수문자를 뺀 글자입니다. 이름이 이상하게 나오면 보석에 마우스를 올리고 `/세공 보석` 을 입력해 나온 글자를 알려 주세요.
- 한 보석을 추천대로 끝냈는데 기록이 안 올랐거나 두 번 올랐으면 `/세공 제보` 를 알려 주세요. 통계 창에서 `+` `-` 로 바로 고칠 수도 있습니다.
- 설정 파일: `journal.on`(true/false). 예전 `tally.on` · `tally.day` · `tally.count` · `tally.sep` · `tally.px` · `tally.py` 는 이제 쓰지 않습니다 (남아 있어도 무시).

### 광채 그림 저장 (v0.8.1)
광채 그림은 서버가 따로 만든 아이템이라 모드가 미리 알 수 없고, 인벤토리에서 **한 번 봐야** 알 수 있습니다. 예전에는 그 그림을 게임을 켜 둔 동안만 기억해서, 껐다 켜면 광채가 인벤토리에 있을 때까지 그림이 안 보였습니다.
- 이제 처음 본 그림을 `config/segong.properties` 의 `icon.0`(바이올렛), `icon.1`(오팔), `icon.2`(아다만티움)에 저장합니다. 다음부터는 게임에 들어가면 인벤토리에 광채가 없어도 그림이 나옵니다.
- 각 광채를 **인벤토리에 가진 상태로 딱 한 번** 게임에 들어와 있으면 저장됩니다.
- 그림이 이상하면 설정 파일에서 `icon.` 으로 시작하는 줄을 지우면 다음에 다시 저장합니다.
- `/세공 제보` 안의 "광채 그림을 본 적" 줄에 "저장됨 O/O/O" 가 같이 나옵니다.

### v0.14.0 에서 달라진 점 (새 기능 + 고침)
- **설정에 "미리보기" 켜짐/꺼짐 추가.** 기본은 **꺼짐**(= v0.13.1처럼 세공 창 모듈 칸에 보석이 있을 때만). **켜짐**으로 바꾸면 예전처럼 인벤토리·창고 등에서 보석에 마우스를 올리기만 해도 카드가 나옵니다 (마우스를 치우면 잠깐 뒤에 사라짐). 설정 파일 `config/segong.properties` 의 `hover.on`(true/false)에 저장됩니다. "설정 기본값으로"를 누르면 꺼짐으로 돌아갑니다.
- **설정 화면 미리보기 카드가 설정 창을 가리지 않습니다.** 예전에는 카드가 내 카드 위치(화면 왼쪽 등)에 그대로 그려져서 설정 창과 겹쳤습니다. 이제 설정 창 **옆의 더 넓은 빈 자리**에 맞춰 그립니다. 자리가 좁으면 카드를 **줄여서**(제목에 "(축소)" 표시) 보여 주고, 너무 좁으면(절반보다 작아지면) 미리보기를 생략합니다. 설정 창은 항상 가운데에 있고 글자 크기 슬라이더를 움직여도 흔들리지 않습니다. 실제 게임에서 카드 위치와 크기는 그대로입니다.
- 화면이 낮을 때(GUI 높이 약 290 이하) 설정 창의 줄 사이를 조금 좁혀서 아래 안내 글자와 겹치지 않게 했습니다.
- 줄이 하나 늘어서 설정 창이 조금 더 커졌습니다 (높이 291).

### v0.13.1 에서 달라진 점 (작은 수정)
- **세공 창이 열려 있고 모듈 칸에 보석이 들어 있을 때만** 카드가 나옵니다. 예전에는 내 인벤토리·창고 같은 데서 보석에 마우스만 올려도, 그리고 세공 창을 닫은 직후에도 잠깐 카드가 떴는데 이제 안 뜹니다. ("모듈 칸" = 열린 창에서 내 인벤토리가 아닌 칸. 세공 창은 보석 칸에 보석을 넣으면 인식합니다.)
- 그래서 **보석을 모듈 칸에 넣기 전에 인벤토리에서 마우스만 올려 미리 추천을 보는 것은 안 됩니다.** (v0.14.0에서 설정 "미리보기"를 켜면 다시 됩니다.)
- 보석이 든 칸이 있는 **다른 창(창고 등)** 에서는 아직 카드가 뜰 수 있습니다. 그런 일이 있으면 그 창을 연 채로는 채팅이 안 되니 닫은 직후에 `/세공 제보` 를 해서 알려 주세요. 점검 내용에 **마지막으로 연 화면 제목**과 **인벤토리 밖 칸 수**가 새로 들어가서, 세공 창만 더 정확히 골라내는 데 씁니다.
- `/세공 보석` 은 이제 마우스를 올린 보석의 글자를 보는 용도로만 쓰입니다 (올린 뒤 채팅창에 입력하는 방법은 그대로).

### v0.13.0 에서 달라진 점 (새 기능 + 정리)
- **통계 창** 추가 (위 설명): `/세공 통계` 또는 설정의 "통계 보기". 기간 탭 · 날짜별 막대 · 보석×등급 표 · 날짜별 자세히 · `+` `-` 로 고치기 · 방금 기록 취소 · 전체 지우기.
- **"오늘 세공 N회" 횟수 기능을 모두 없앴습니다**: 카드 안의 횟수 표시, 따로 띄우는 횟수 알약(끌어서 옮기기 포함), 설정의 "세공 횟수" · "횟수 표시" 줄, `/세공 횟수` 명령어(추가/빼기/초기화, 영어 `count`). 횟수는 이제 "오늘한 세공" 표와 통계 창의 합계로 봅니다.
- **채팅창 통계 하위 명령을 없앴습니다**: `/세공 통계 어제` · `전체` · `날짜` · `취소` · `초기화` (영어 포함). 이제 `/세공 통계` 는 뒤에 뭘 붙여도 통계 창만 엽니다. 같은 일은 통계 창에서 합니다.

### 추천 고정 (v0.5.1)
광채를 하나 넣을 때마다 보석 수치와 보유 개수가 바뀌는데, 예전에는 그때마다 처음부터 다시 계산해서 목표가 계속 바뀌었습니다. (같은 합이 나오는 방법이 여러 개라서, 보유 개수 비율에 따라 다른 방법이 뽑힘.)
- 보석을 처음 본 순간 정한 목표를 기억하고, 광채를 넣으면 **남은 개수만** 줄어듭니다. 다 넣으면 "추가 필요 없음".
- 추천(몇 개를 넣을지)은 그대로 유지하고 남은 개수만 줄어듭니다. "보유" 숫자는 **내 인벤토리를 그대로 센 값**이라 오른쪽 인벤토리 창의 숫자와 같습니다. (v0.9.0부터. 예전에는 광채를 칸에 올려도 보유가 그대로 보였습니다.)
- 다른 보석을 보거나 보석 수치가 계획과 안 맞으면 새로 계산합니다. 보석을 10초 넘게 안 보고 있다가(화면을 닫았다 열기 등) 다시 보면 새로 계산합니다.
- 다시 계산하고 싶으면 `V` 를 두 번(껐다 켜기) 누르거나, 설정에서 추천 고정을 껐다 켜면 됩니다.
- 설정 파일의 `lock` 값 (`true`/`false`).

## 키 (마크 설정 > 조작에서 변경 가능)
- `V` : 켜기/끄기 (세공 화면이 열려 있어도 동작)
- `G` : 등급 한도 바꾸기 (자동 이 안 될 때)
- `K` : 설정 화면 열기 (게임 중에만)
(글자 입력칸에 커서가 있을 때는 키가 무시됩니다.)

## 명령어 (채팅창에 입력 — 화면 닫은 뒤)
명령어는 `/세공` 으로 시작하고, 뒤에 붙는 이름도 한글입니다. (예전 영어 이름과 `/segong` 도 그대로 쓸 수 있습니다. 괄호 안이 영어 이름.)
- `/세공` 또는 `/세공 도움말` (help) : 키와 명령어 목록을 채팅창에 보여줍니다.
- `/세공 설정` (settings) : 설정 화면 열기
- `/세공 통계` (stats) : **통계 창**을 엽니다 (어떤 보석을 몇 번 세공했는지, 날짜별·등급별. 창에서 고치거나 지울 수도 있습니다).
- `/세공 제보` (report) : 문제가 생겼을 때 쓰는 명령어. 점검 내용과 최근 기록을 **한 번에 복사**합니다. 디스코드에 Ctrl+V 로 붙여넣어 알려 주세요.
- `/세공 인벤` (inv, inventory) : 인벤토리에서 센 광채 개수
- `/세공 아이템` (items) : 인벤토리 아이템 이름 목록 (광채가 0개로 나올 때)
- `/세공 칸` (slots) : 열린 화면의 인벤토리 밖 칸 목록 (세공 화면은 채팅이 안 쳐져서 거의 쓸 일 없음)
- `/세공 보석` (dump) : 마지막으로 본 보석의 툴팁 글자와 등급 표시 문자

## 만드는 법 (둘 중 편한 것)

### 방법 A. GitHub에서 자동으로 (설치 필요 없음, 추천)
1. github.com 에서 새 저장소(Repository)를 만듭니다.
2. 이 폴더 안의 파일을 전부 올립니다. (`.github` 폴더 포함)
3. 위쪽 **Actions** 탭 → build 가 초록색 체크가 될 때까지 기다립니다.
4. 완료된 항목을 열면 아래쪽 **Artifacts** 에 `segong-helper-jar` 가 있습니다. 받아서 압축을 풀면 jar 파일이 나옵니다.
   (`-sources.jar` 가 아닌 `segong-helper-0.1.0.jar` 를 쓰세요)

### 방법 B. 내 컴퓨터에서
1. Java 21 설치 (Temurin 21 등)
2. 이 폴더에서 명령 프롬프트를 열고 `gradlew build` (맥/리눅스는 `./gradlew build`)
3. `build/libs/segong-helper-0.1.0.jar` 가 생깁니다.

## 설치
1. Fabric Loader 0.16 이상, Minecraft 1.21.4, **Fabric API** 가 설치돼 있어야 합니다.
2. jar 를 `.minecraft/mods` 폴더에 넣습니다.

화면에 정보를 보여주기만 하지만, 서버마다 모드 규정이 다릅니다. 사용 전에 운영진에게 허용되는지 한 번 물어보세요.

## 알려진 한계 (이 버전은 아직 한 번도 컴파일/실행해 보지 못했습니다)
- 만든 환경에서 마인크래프트/Fabric 사이트에 접속이 막혀 **빌드를 못 해봤습니다.** 빌드 오류가 나면 오류 글자를 그대로 알려주세요.
- 광채 이름에 "바이올렛/오팔/아다만티움"과 "광채"가 들어 있다고 가정했습니다. `/세공 아이템` 으로 확인하세요.
- 세공 화면에 있는 "2세트 / 총 128개" 가 실제 인벤토리의 아이템과 같은지는 `/세공 인벤` 으로 확인해야 합니다.
- 계산 부분(Calc)은 웹 계산기와 403개 시험 입력으로 답이 같음을 확인했습니다.

## 버전 규칙
`gradle.properties` 의 `mod_version` 이 jar 이름과 설정 화면 오른쪽 위 `v…` 에 표시됩니다.
- 작은 수정: 맨 오른쪽 +1 (0.1.1 → 0.1.2 …)
- 새 기능 추가: 가운데 +1, 오른쪽은 0 (0.1.x → 0.2.0)
- 아주 큰 변경: 맨 왼쪽 +1
